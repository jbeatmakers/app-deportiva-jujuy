🏆 App Deportiva Jujuy

Plataforma de Deportes de la Provincia de Jujuy

🚀 API Endpoints Disponibles

GET / - Información de la aplicación

GET /deportes - Lista de todos los deportes

GET /deportes/:id - Información de un deporte específico

GET /health - Estado de la aplicación

🏅 Deportes de Jujuy

Haz clic en "Cargar Deportes" para ver la información...

📚 Cómo usar esta API

Para probar la API localmente:

  1. Clona el repositorio: git clone https://github.com/jbeatmakers/app-deportiva-jujuy.git
  2. Instala dependencias: pip install -r requirements.txt
  3. Ejecuta la app: python app.py
  4. Abre: http://localhost:5000
